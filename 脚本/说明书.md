# Scripts

此目录包含用于构建各平台二进制的脚本。

项目没有 `CGO` 依赖，直接使用 `go build` 即可构建。

由于依赖 `pion/webrtc`、`golang.org/x` 等第三方 Go 库，项目需使用较新 Go 版本，这可能影响旧操作系统兼容性。

项目使用 [UPX](https://github.com/upx/upx) 压缩 Linux 二进制。Windows 不压缩，以避免杀毒软件误报；macOS 不压缩，因为压缩结果无法正常使用。

<a id="useful-commands"></a>

## 实用命令

```
go get -u
go mod tidy
go mod why github.com/pion/rtcp
go list -deps .\cmd\go2rtc_rtsp\
./goweight
```
