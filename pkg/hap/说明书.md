# 家庭配件协议

> 附注：代码中的 Character 指 Characteristic，即特征属性。

**设备（Device）**：HomeKit 终端设备，例如开关、摄像头。

- mDNS 名称：`MyCamera._hap._tcp.local.`
- DeviceID：类似 MAC 地址，`0E:AA:CE:2B:35:71`
- HomeKit 设备描述包括：
  - 一个或多个 `Accessories`，包含 `AID` 和 `Services`
  - `Services`，包含 `IID`、`Type` 和 `Characters`
  - `Characters`，包含 `IID`、`Type`、`Format` 和 `Value`

**客户端（Client）**：HomeKit 客户端，例如 iPhone、iPad、MacBook 或开源库。

- ClientID：固定的随机 UUID
- ClientPublic/ClientPrivate：固定的随机 32 字节密钥对
- 可通过 PIN 与设备配对，交换 ClientID/ClientPublic 和 ServerID/ServerPublic
- 可用 ClientPrivate 向设备验证身份
- 与设备保持持久安全连接
- 可读取设备配件
- 可读写设备特征属性
- 可订阅设备特征属性变化事件

**服务器（Server）**：HomeKit 服务端，可以是终端设备软件或开源库。

- ServerID：与 DeviceID 相同，用于客户端身份验证
- ServerPublic/ServerPrivate：固定的随机 32 字节密钥对

## AAC-ELD

需要编译时启用 `--enable-libfdk-aac` 的 FFmpeg。

```
-acodec libfdk_aac -aprofile aac_eld 
```

| SampleRate | RTPTime | constantDuration   | objectType   |
|------------|---------|--------------------|--------------|
| 8000       | 60      | =8000/1000*60=480  | 39 (AAC ELD) |
| 16000      | 30      | =16000/1000*30=480 | 39 (AAC ELD) |
| 24000      | 20      | =24000/1000*20=480 | 39 (AAC ELD) |
| 16000      | 60      | =16000/1000*60=960 | 23 (AAC LD)  |
| 24000      | 40      | =24000/1000*40=960 | 23 (AAC LD)  |
