# 网站

这是 [go2rtc.org](https://go2rtc.org/) 网站的源文件。内容发布在 GitHub Pages，也是 [alexxit.github.io/go2rtc/](http://alexxit.github.io/go2rtc/) 的镜像。

网站包含：

- 项目文档：由 [vitepress](https://github.com/vuejs/vitepress) 从仓库根目录和 `internal` 目录内的 `说明书.md` 文件编译生成
- OpenAPI 格式接口文档及 [Redoc](https://github.com/Redocly/redoc) 查看器
- 项目资源，例如标志图案
