# www

此目录包含构建时嵌入应用的静态 HTTP 和 JavaScript 内容，可作为集成 go2rtc 或开发自定义网页界面的基础。

<a id="http-api"></a>

## HTTP 接口

`www/视频预览.html`：通用播放器，支持以下地址参数：

- 页面内显示多个流：`src=camera1&src=camera2...`
- 自动选择播放技术：`mode=webrtc,webrtc/tcp,mse,hls,mp4,mjpeg`
- 比较播放技术：`src=camera1&mode=webrtc&mode=mse&mode=mp4`
- 用像素 `width=320px` 或百分比 `width=50%` 设置播放器宽度

`www/WebRTC预览.html`：支持双向对讲的 WebRTC 播放器，支持以下地址参数：

- `media=video+audio`：普通预览
- `media=video+audio+microphone`：摄像头双向对讲
- `media=camera+microphone`：从浏览器推流
- `media=display+speaker`：从桌面推流

<a id="javascript-api"></a>

## JavaScript 接口

- 可从零编写播放器
- 可扩展内置播放器：`www/实时播放器.js`
- 示例：`www/视频流播放器.js`
- 示例：https://github.com/AlexxIT/WebRTC

`实时播放器.js` features:

- 支持的技术：
    - 通过 UDP 或 TCP 传输 WebRTC
    - 通过 WebSocket 传输 MSE、HLS、MP4 或 MJPEG
- 根据以下条件自动选择最佳技术：
    - 流的编码
    - 当前浏览器能力
    - 当前网络配置
- 浏览器或页面不活动时自动停止流
- 播放器离开页面可见区域时自动停止流
- 自动重连

技术选择优先级：

1. 同时有视频和音频优于仅视频
2. H265 优于 H264
3. WebRTC 优于 MSE，其次 HLS，最后 MJPEG

<a id="browser-support"></a>

## 浏览器支持

[iOS 12](https://en.wikipedia.org/wiki/IOS_12)（iPhone 5S、iPad Air、iPad Mini 2 等）支持 [ECMAScript 2019 (ES10)](https://caniuse.com/?search=es10)。

[ECMAScript 2017 (ES8)](https://caniuse.com/?search=es8) 也基本可用（`es6 + async`），并且是 [React+TypeScript](https://github.com/typescript-cheatsheets/react) 的推荐版本。
