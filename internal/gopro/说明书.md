# GoPro

[`v1.8.3 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.8.3)

支持通过 USB 或 Wi-Fi 连接到 Linux、Mac、Windows 的 [GoPro](https://gopro.com/) 摄像头。

支持型号：HERO9、HERO10、HERO11、HERO12。
支持系统：Linux、Mac、Windows、[HassOS](https://www.home-assistant.io/installation/)

其他型号使用不同接口，原作者计划在未来版本添加支持。

<a id="configuration"></a>

## 配置

- USB 摄像头会在系统中创建新的网络接口
- Linux 用户无需安装额外软件
- Windows 用户应安装 [network driver](https://community.gopro.com/s/article/GoPro-Webcam)
- 如能发现摄像头但无法启动流，请检查防火墙是否阻止连接

1. 发现摄像头地址：网页界面 > 添加 > GoPro
2. 将摄像头添加到配置

```yaml
streams:
  hero12: gopro://172.20.100.51
```
