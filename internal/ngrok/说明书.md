# ngrok

使用 ngrok 集成，即使网络位于私有 IP 后，也可从外部访问流。

- 两种功能可能需要分别配置外部访问：
    - WebRTC 流：转发 WebRTC TCP 端口，例如 8555
    - go2rtc 网页界面：转发 HTTP 接口端口，例如 1984
- ngrok 支持为网页界面设置身份验证
- ngrok 自动为网页界面提供 HTTPS

ngrok 免费订阅有以下限制：

- 可为网页界面预留免费域名，但 TCP 地址始终随机，且每次重启 ngrok 代理都会变化；这不影响 WebRTC 流
- 单个代理可转发多个端口，但免费方案只能运行一个 ngrok 代理

启用 ngrok 配置中的 TCP 转发后，go2rtc 会自动获取外部 TCP 地址；同时启用 WebRTC 配置时，将使用该地址建立 WebRTC 连接。

需要为操作系统手动下载 [ngrok agent](https://ngrok.com/download)，并注册 [ngrok service](https://ngrok.com/signup)。

**仅为 WebRTC 流建立隧道**

需要在 YAML 中添加 [ngrok authtoken](https://dashboard.ngrok.com/get-started/your-authtoken) 和 WebRTC TCP 端口：

```yaml
ngrok:
  command: ngrok tcp 8555 --authtoken eW91IHNoYWxsIG5vdCBwYXNzCnlvdSBzaGFsbCBub3QgcGFzcw
```

**同时为 WebRTC 和网页界面建立隧道**

需要创建 `ngrok.yaml` 配置文件，并将其加入 go2rtc 配置：

```yaml
ngrok:
  command: ngrok start --all --config ngrok.yaml
```

ngrok 配置示例：

```yaml
version: "2"
authtoken: eW91IHNoYWxsIG5vdCBwYXNzCnlvdSBzaGFsbCBub3QgcGFzcw
tunnels:
  api:
    addr: 1984  # use the same port as in the go2rtc config
    proto: http
    basic_auth:
      - admin:password  # you can set login/pass for your web interface
  webrtc:
    addr: 8555  # use the same port as in the go2rtc config
    proto: tcp
```

ngrok 配置文件详情见 [ngrok agent documentation](https://ngrok.com/docs/agent/config/)。
