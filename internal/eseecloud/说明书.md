# EseeCloud

[`v1.9.10 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.9.10)

此源用于链接形如 `http://admin:@192.168.1.123:80/livestream/12` 的摄像头，相关问题见 [issue](https://github.com/AlexxIT/go2rtc/issues/1690)。

<a id="configuration"></a>

## 配置

```yaml
streams:
  camera1: eseecloud://user:pass@192.168.1.123:80/livestream/12
```
