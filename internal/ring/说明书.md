# Ring

[`v1.9.13 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.9.13) by [@seydx](https://github.com/seydx)

此源支持具备 [two-way audio](../../说明书.md#two-way-audio) 功能的 Ring 摄像头。

<a id="configuration"></a>

## 配置

已有 `refresh_token` 和 `device_id` 时，可直接用于 `go2rtc.yaml` 配置文件。

否则可在网页界面添加 Ring 账户（网页界面 > 添加 > Ring），添加后会列出全部 Ring 摄像头。

```yaml
streams:
  ring: ring:?device_id=XXX&refresh_token=XXX
  ring_snapshot: ring:?device_id=XXX&refresh_token=XXX&snapshot
```
