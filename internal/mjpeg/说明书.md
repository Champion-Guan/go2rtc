# 动态 JPEG

- 此模块可提供和接收 MJPEG 格式流
- 此模块也负责获取 JPEG 格式快照
- 此模块还支持以**动态字符画**形式向服务器控制台（终端）输出视频流

<a id="mjpeg-client"></a>

## MJPEG 客户端

**重要：**输出 MJPEG 流时，源必须包含 MJPEG 编码。存在该编码时，可通过接口获取 **MJPEG 流**或 **JPEG 快照**。

获取 MJPEG 流的方式包括：

- 部分摄像头在 [RTSP stream](../rtsp/说明书.md) 中支持 MJPEG 编码，例如大华第二码流
- 部分摄像头提供 [MJPEG stream](../http/说明书.md) HTTP 链接
- 部分摄像头提供 HTTP 快照链接，go2rtc 可将其转换为 [MJPEG stream](../http/说明书.md)
- 可通过 [FFmpeg integration](../ffmpeg/说明书.md) 转换摄像头的 H264/H265 流

使用以下示例后，同一流将同时包含 H264 和 MJPEG 编码：

```yaml
streams:
  camera1:
    - rtsp://rtsp:12345678@192.168.1.123/av_stream/ch0
    - ffmpeg:camera1#video=mjpeg
```

<a id="mjpeg-server"></a>

## MJPEG 服务器

### mpjpeg

输出 [MJPEG](https://en.wikipedia.org/wiki/Motion_JPEG) 格式流。[FFmpeg](https://ffmpeg.org/) 中称其为 `mpjpeg`，因为它包含 HTTP 头。

```
ffplay http://192.168.1.123:1984/api/stream.mjpeg?src=camera1
```

### jpeg

获取 JPEG 快照：

```
curl http://192.168.1.123:1984/api/frame.jpeg?src=camera1
```

- 可使用 `width`/`w` 和/或 `height`/`h` 参数
- `rotate` 参数可取 `90`、`180`、`270` 或 `-90`
- 可使用 `hardware`/`hw` 参数 [read more](https://github.com/AlexxIT/go2rtc/wiki/Hardware-acceleration)
- 可使用 `cache` 参数（`1m`、`10s` 等）获取缓存快照
  - 只有请求包含 `cache` 参数时，快照才会被缓存
  - 缓存快照未超过 `cache` 指定的时限时才会使用
  - `cache` 参数不会检查缓存图像尺寸是否与查询指定的尺寸一致

### ascii

以字符画形式向终端输出流。这主要用于趣味展示，可在没有图形界面的服务器控制台观看摄像头。

[![](https://img.youtube.com/vi/sHj_3h_sX7M/mqdefault.jpg)](https://www.youtube.com/watch?v=sHj_3h_sX7M)

> 演示视频组合了多项字符画设置并添加音频，此格式本身并不直接支持音频。

**Tips**

- 仅支持 MJPEG 编码，其他编码需转码
- 请选择较低帧率
- 请根据终端大小选择宽度和高度
- 不同终端支持的颜色数量不同，如 8 色、256 色、RGB 真彩色
- 对 `text` 参数进行 URL 编码
- 可使用任意摄像头或磁盘文件

**go2rtc.yaml**：转码为 MJPEG，终端尺寸 210×59（16:9），帧率 10

```yaml
streams:
  gamazda: ffmpeg:gamazda.mp4#video=mjpeg#hardware#width=210#height=59#raw=-r 10
```

**接口参数**

- `color`：前景色，可为空或为 `8`、`256`、`rgb`、[SGR](https://en.wikipedia.org/wiki/ANSI_escape_code)
  - example: `30` (black), `37` (white), `38;5;226` (yellow)
- `back`：背景色，可为空或为 `8`、`256`、`rgb`、[SGR](https://en.wikipedia.org/wiki/ANSI_escape_code)
  - example: `40` (black), `47` (white), `48;5;226` (yellow)
- `text`：字符集，可为空、单个字符、`block` 或按亮度排序的字符列表
  - 示例：`%20`（空格）、`block`（块元素关键字）、`ox`（两个字符）

**Examples**

```bash
% curl "http://192.168.1.123:1984/api/stream.ascii?src=gamazda"
% curl "http://192.168.1.123:1984/api/stream.ascii?src=gamazda&color=256"
% curl "http://192.168.1.123:1984/api/stream.ascii?src=gamazda&back=256&text=%20"
% curl "http://192.168.1.123:1984/api/stream.ascii?src=gamazda&back=8&text=%20%20"
% curl "http://192.168.1.123:1984/api/stream.ascii?src=gamazda&text=helloworld"
```

### yuv4mpegpipe

带 [YUV4MPEG](https://manned.org/yuv4mpeg) 头的原始 [YUV](https://en.wikipedia.org/wiki/Y%E2%80%B2UV) 帧流。

```
ffplay http://192.168.1.123:1984/api/stream.y4m?src=camera1
```

<a id="streaming-ingest"></a>

## 接收推流

```shell
ffmpeg -re -i BigBuckBunny.mp4 -c mjpeg -f mpjpeg http://localhost:1984/api/stream.mjpeg?dst=camera1
```
