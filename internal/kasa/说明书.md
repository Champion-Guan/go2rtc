# TP-Link Kasa

[`v1.7.0 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.7.0)

[TP-Link Kasa](https://www.kasasmart.com/) 使用非标准协议 [more info](https://medium.com/@hu3vjeen/reverse-engineering-tp-link-kc100-bac4641bf1cd)。

- `username`：适用于 URL 的邮箱编码，`alex@gmail.com` 转为 `alex%40gmail.com`
- `password` - base64password, `secret1` -> `c2VjcmV0MQ==`

```yaml
streams:
  kc401: kasa://username:password@192.168.1.123:19443/https/stream/mixed
```

Tested: KD110, KC200, KC401, KC420WS, EC71.
