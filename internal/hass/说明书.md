# Home Assistant

支持从 [Home Assistant](https://www.home-assistant.io/) 配置文件导入摄像头链接：

- [Generic Camera](https://www.home-assistant.io/integrations/generic/)，通过图形界面设置
- [HomeKit Camera](https://www.home-assistant.io/integrations/homekit_controller/)
- [ONVIF](https://www.home-assistant.io/integrations/onvif/)
- 带摄像头的 [Roborock](https://github.com/humbertogontijo/homeassistant-roborock) 扫地机器人

<a id="configuration"></a>

## 配置

```yaml
hass:
  config: "/config"  # skip this setting if you are a Home Assistant add-on user

streams:
  generic_camera: hass:Camera1  # Settings > Integrations > Integration Name
  aqara_g3: hass:Camera-Hub-G3-AB12
```

<a id="webrtc-cameras"></a>

### WebRTC 摄像头

[`v1.6.0 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.6.0)

支持任意 WebRTC 格式的摄像头。目前 Home Assistant 仅支持部分 [Nest](https://www.home-assistant.io/integrations/nest/) 摄像头使用此格式。

**重要：**Nest 接口获取的流链接仅有效 5 分钟。
不要将此方式用于 Frigate！流过期后，Frigate 可能在数秒内耗尽机器的可用内存。
推荐使用 [Nest source](../nest/说明书.md)，它支持延长流的有效期。

```yaml
streams:
  # 连接 Home Assistant Supervised
  hass-webrtc1: hass://supervisor?entity_id=camera.nest_doorbell
  # 连接外部 Home Assistant，使用长期访问令牌
  hass-webrtc2: hass://192.168.1.123:8123?entity_id=camera.nest_doorbell&token=eyXYZ...
```

<a id="rtsp-cameras"></a>

### RTSP 摄像头

默认情况下，Home Assistant 接口不允许获取摄像头动态 RTSP 链接；[此方法](https://github.com/felipecrs/hass-expose-camera-stream-source#importing-cameras-from-home-assistant-to-go2rtc-or-frigate) 可解决此限制。
