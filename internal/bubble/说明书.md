# Bubble

[`v1.6.1 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.6.1)

[dvr163.com](http://help.dvr163.com/) 和 [eseecloud.com](http://www.eseecloud.com/) 的部分摄像头使用的私有格式。

<a id="configuration"></a>

## 配置

- 使用默认值时，可省略 `username`、`password`、`port`、`ch` 和 `stream`
- 请为不同通道和码流分别设置流

```yaml
streams:
  camera1: bubble://username:password@192.168.1.123:34567/bubble/live?ch=0&stream=0
```
