# 动态链接脚本（echo）

部分视频源的链接是动态的，需要通过 Bash 或 Python 脚本获取。脚本应输出源链接，可以是 RTSP、FFmpeg 或其他受支持的源。

**Docker** 和 **Home Assistant 附加组件**已预装 `python3`、`curl`、`jq`。

<a id="configuration"></a>

## 配置

```yaml
streams:
  apple_hls: echo:python3 hls.py https://developer.apple.com/streaming/examples/basic-stream-osx-ios5.html
```

<a id="install-python-libraries"></a>

## 安装 Python 库

**Docker** 和 **Home Assistant 附加组件**预装了 `python3`，但未附带 [requests](https://requests.readthedocs.io/) 等额外库。如有需要，请将库安装到脚本所在目录：

1. 安装 [SSH & Web Terminal](https://github.com/hassio-addons/addon-ssh)
2. 打开附加组件网页界面
3. 安装库：`pip install requests -t /config/echo`
4. 将脚本添加到 `/config/echo/myscript.py`
5. 将脚本用作源：`echo:python3 /config/echo/myscript.py`

<a id="example-apple-hls"></a>

## 示例：Apple HLS

```yaml
streams:
  apple_hls: echo:python3 hls.py https://developer.apple.com/streaming/examples/basic-stream-osx-ios5.html
```

**hls.py**

```python
import re
import sys
from urllib.parse import urljoin
from urllib.request import urlopen

html = urlopen(sys.argv[1]).read().decode("utf-8")
url = re.search(r"https.+?m3u8", html)[0]

html = urlopen(url).read().decode("utf-8")
m = re.search(r"^[a-z0-1/_]+\.m3u8$", html, flags=re.MULTILINE)
url = urljoin(url, m[0])

# ffmpeg:https://devstreaming-cdn.apple.com/videos/streaming/examples/bipbop_16x9/gear1/prog_index.m3u8#video=copy
print("ffmpeg:" + url + "#video=copy")
```
