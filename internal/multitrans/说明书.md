# TP-Link MULTITRANS

[`v1.9.14 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.9.14) by [@forrestsocool](https://github.com/forrestsocool)

支持中国版 [TP-Link](https://www.tp-link.com.cn/) 摄像头的双向对讲。

<a id="configuration"></a>

## 配置

```yaml
streams:
  tplink_cam:
    # 视频使用标准 RTSP
    - rtsp://admin:admin@192.168.1.202:554/stream1
    # 双向音频使用 MULTITRANS 协议
    - multitrans://admin:admin@192.168.1.202:554
```
