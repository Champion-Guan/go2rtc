# 实时消息传输协议

此模块为 RTMP 协议提供以下功能：

- 流输入：[RTMP client](#rtmp-client)
- `rtmp` 格式流输出和接收推流：[RTMP server](#rtmp-server)
- `flv` 格式流输出和接收推流：[FLV server](#flv-server)

<a id="rtmp-client"></a>

## RTMP 客户端

可从 RTMP 服务器获取流，例如 [Nginx with nginx-rtmp-module](https://github.com/arut/nginx-rtmp-module)。

<a id="client-configuration"></a>

### 客户端配置

```yaml
streams:
  rtmp_stream: rtmp://192.168.1.123/live/camera1
```

<a id="rtmp-server"></a>

## RTMP 服务器

[`v1.8.0 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.8.0)

输出 `rtmp` 格式流：

```shell
ffplay rtmp://localhost:1935/camera1
```

接收 `rtmp` 格式推流：

```shell
ffmpeg -re -i BigBuckBunny.mp4 -c copy -f flv rtmp://localhost:1935/camera1
```

<a id="server-configuration"></a>

### 服务器配置

RTMP 服务器默认关闭。

```yaml
rtmp:
  listen: ":1935"  # by default - disabled!
```

<a id="flv-server"></a>

## FLV 服务器

输出 `flv` 格式流。

```shell
ffplay http://localhost:1984/stream.flv?src=camera1
```

接收 `flv` 格式推流。

```shell
ffmpeg -re -i BigBuckBunny.mp4 -c copy -f flv http://localhost:1984/api/stream.flv?dst=camera1
```

**OBS**
 
设置 > 推流：

- Server: rtmp://192.168.10.101/tmp
- 推流密钥：`<empty>`
- 启用身份验证：`<disabled>`

**OpenIPC**

网页界面 > Majestic > 设置 > 输出

- Enable
- Address: rtmp://192.168.10.101/tmp
