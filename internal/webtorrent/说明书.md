<a id="webtorrent-server"></a>

## WebTorrent 服务器

[`v1.3.0 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.3.0)

此模块支持：

- 通过 [WebTorrent](https://webtorrent.io/) 技术分享任意本地流
- 通过 [WebTorrent](https://webtorrent.io/) 技术从电脑或手机获取任意 [incoming stream](../webrtc/说明书.md#ingest-browser)
- 通过 [WebTorrent](https://webtorrent.io/) 技术获取远程 go2rtc 源

这些功能免费且安全，无需为 go2rtc 服务器开放公网访问。但对称 NAT 等情况下可能需要配置 [WebRTC module](../webrtc/说明书.md) 的外部访问。

在网页界面的流链接页面生成分享或输入链接。链接是**临时的**，重启 go2rtc 后失效。

<a id="server-configuration"></a>

### 服务器配置

可在 go2rtc 配置中创建永久外部链接：

```yaml
webtorrent:
  shares:
    super-secret-share:  # share name, should be unique among all go2rtc users!
      pwd: super-secret-password
      src: rtsp-dahua1   # stream name from streams section
```

链接示例：`https://go2rtc.org/webtorrent/#share=02SNtgjKXY&pwd=wznEQqznxW&media=video+audio`
