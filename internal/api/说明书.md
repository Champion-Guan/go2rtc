# HTTP 接口

HTTP 接口是与应用交互的主要方式，默认地址为 `http://localhost:1984/`。

HTTP 接口采用 [OpenAPI](../../网站/api/openapi.yaml) 格式描述，可在 [交互式查看器](https://go2rtc.org/api/) 中浏览；WebSocket 接口见 [此处](ws/说明书.md)。

项目的静态 HTML 和 JavaScript 文件位于 [www](../../www/说明书.md) 目录。外部开发者可以据此将 go2rtc 集成到自己的项目，或开发自定义网页界面。

构建时，`www` 目录会嵌入 go2rtc；也可以通过配置指定外部目录作为静态文件来源。

<a id="configuration"></a>

## 配置

**重要！** 即使配置了 HTTP 身份验证，go2rtc 默认仍会放行来自本机和 Unix 套接字的请求。请自行配置安全的外部接口访问方式；配置不当可能使攻击者访问摄像头甚至服务器。

- 使用 `listen: ""` 可禁用 HTTP 接口，例如只使用 RTSP 客户端/服务器协议
- 使用 `listen: "127.0.0.1:1984"` 可将 HTTP 接口限制为仅本机访问
- 可修改接口的 `base_path`，将 go2rtc 挂载到主应用网页服务器的子路径
- `static_dir` 中的全部文件均从根路径 `/` 提供
- TLS 证书和密钥既可填写原始内容，也可填写文件路径

```yaml
api:
  listen: ":1984"    # default ":1984", HTTP API port ("" - disabled)
  username: "admin"  # default "", Basic auth for WebUI
  password: "pass"   # default "", Basic auth for WebUI
  local_auth: true   # default false, Enable auth check for localhost requests
  base_path: "/rtc"  # default "", API prefix for serving on suburl (/api => /rtc/api)
  static_dir: "www"  # default "", folder for static files (custom web interface)
  origin: "*"        # default "", allow CORS requests (only * supported)
  tls_listen: ":443" # default "", enable HTTPS server
  tls_cert: |        # default "", PEM-encoded fullchain certificate for HTTPS
    -----BEGIN CERTIFICATE-----
    ...
    -----END CERTIFICATE-----
  tls_key: |         # default "", PEM-encoded private key for HTTPS
    -----BEGIN PRIVATE KEY-----
    ...
    -----END PRIVATE KEY-----
  unix_listen: "/tmp/go2rtc.sock"  # default "", unix socket listener for API
```

**PS:**

- 由于 Chrome 的 [bug](https://bugs.chromium.org/p/chromium/issues/detail?id=527446)，通过 WebSocket 播放 MJPEG 比原生 MJPEG 更流畅
- 通过 WebSocket 播放 MP4 专为不支持文件流式播放的 Apple iOS 设计
