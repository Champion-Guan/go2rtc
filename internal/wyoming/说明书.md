# Wyoming

> [!NOTE]
> 此格式仍在开发中，尚不稳定。

此模块提供 [Wyoming Protocol](https://www.home-assistant.io/integrations/wyoming/) 支持，可使用 [Home Assistant](https://www.home-assistant.io/) 创建本地语音助手。

- go2rtc 可充当 [Wyoming Satellite](https://github.com/rhasspy/wyoming-satellite)
- go2rtc 可充当 [Wyoming External Microphone](https://github.com/rhasspy/wyoming-mic-external)
- go2rtc 可充当 [Wyoming External Sound](https://github.com/rhasspy/wyoming-snd-external)
- 任意支持 PCM 编码的音频源均可作为输入
- 任意支持 PCM 编码和双向音频的源均可作为输出
- 任意桌面或服务器的麦克风、扬声器均可作为双向音频源
  - 通过 FFmpeg 或类似软件支持任意操作系统
  - Linux 可使用 ALSA 源
- 可用内置脚本引擎修改行为

<a id="typical-voice-pipeline"></a>

## 典型语音处理流程

1. 麦克风音频流（MIC）
   - 支持 PCM 编码的任意音频源，包括 PCMA/PCMU
2. 语音活动检测（VAD）
3. 唤醒词检测（WAKE）
   - [OpenWakeWord](https://www.home-assistant.io/voice_control/create_wake_word/)
4. 语音转文字（STT）
   - [Whisper](https://github.com/home-assistant/addons/blob/master/whisper/) 
   - [Vosk](https://github.com/rhasspy/hassio-addons/blob/master/vosk/)
5. 对话代理（INTENT）
   - [Home Assistant](https://www.home-assistant.io/integrations/conversation/)
6. 文字转语音（TTS）
   - [Google Translate](https://www.home-assistant.io/integrations/google_translate/)
   - [Piper](https://github.com/home-assistant/addons/blob/master/piper/)
7. 音频输出流（SND）
   - 支持双向音频回传和 PCM 编码的任意源，包括 PCMA/PCMU

借助 Home Assistant，可使用许多不同项目完成唤醒、语音识别、对话和语音合成。

借助 go2rtc，可使用多种技术实现音频输入和输出。

<a id="configuration"></a>

## 配置

可选配置唤醒服务，让 go2rtc 仅在检测到唤醒词后向 Home Assistant 传输音频。未配置或无法连接唤醒服务时，会传输全部音频，此时需在语音助手流程中配置唤醒服务。

可选配置 VAD 阈值，让 go2rtc 仅在检测到声音后向唤醒服务传输音频。

流必须支持 PCM 音频传输，包括 PCMA/PCMU。

```yaml
wyoming:
  stream_name_from_streams_section:
    listen: :10700 
    name: "My Satellite"                # optional name
    wake_uri: tcp://192.168.1.23:10400  # optional WAKE service
    vad_threshold: 1                    # optional VAD threshold (from 0.1 to 3.5)
```

Home Assistant > 设置 > 集成 > 添加 > Wyoming 协议 > 填写 `go2rtc.yaml` 中的主机和端口

选择一个或多个唤醒词：
```yaml
wake_uri: tcp://192.168.1.23:10400?name=alexa_v0.1&name=hey_jarvis_v0.1&name=hey_mycroft_v0.1&name=hey_rhasspy_v0.1&name=ok_nabu_v0.1
```

## Events

可使用 [expr](../expr/说明书.md) 语言添加 Wyoming 事件处理，例如通过 Home Assistant 媒体播放器播放合成语音。

启用日志可查看发生的事件。

默认脚本如下：

```yaml
wyoming:
  script_example:
    event:
      run-satellite: Detect()
      pause-satellite: Stop()
      voice-stopped: Pause()
      audio-stop: PlayAudio() && WriteEvent("played") && Detect()
      error: Detect()
      internal-run: WriteEvent("run-pipeline", '{"start_stage":"wake","end_stage":"tts"}') && Stream()
      internal-detection: WriteEvent("run-pipeline", '{"start_stage":"asr","end_stage":"tts"}') && Stream()
```

支持的函数和变量：

- `Detect()`：开始 VAD 和唤醒词检测
- `Stream()`：开始向客户端（Home Assistant）传输音频
- `Stop()`：停止并断开流，但不断开客户端（Home Assistant）
- `Pause()`：暂时暂停音频传输，不断开流
- `PlayAudio()`：播放客户端（Home Assistant）最近发送的音频
- `WriteEvent(type, data)`：向客户端（Home Assistant）发送事件
- `Sleep(duration)`：暂时暂停脚本，例如 `Sleep('1.5s')`
- `PlayFile(path)`：播放 `wav` 文件中的音频
- `Type`：事件类型或名称
- `Data`：JSON 格式事件数据，例如 `{"text":"how are you"}`
- 也可使用 [expr](../expr/说明书.md) 模块的其他函数，例如 `fetch`

为事件编写脚本后，默认动作不再执行，需要在脚本中自行重复所需步骤。

除标准事件外，还有两个附加事件：

- `internal-run`：在 `Detect()` 后检测到 VAD，但唤醒服务不可用时调用
- `internal-detection`：在 `Detect()` 后检测到唤醒词时调用

**示例一：**检测到唤醒词时播放声音文件，仅支持 `wav`：

- `PlayFile` 和 `PlayAudio` 同步执行，后续步骤会等待它们完成

```yaml
wyoming:
  script_example:
    event:
      internal-detection: PlayFile('/media/beep.wav') && WriteEvent("run-pipeline", '{"start_stage":"asr","end_stage":"tts"}') && Stream()
```

**示例二：**通过 Home Assistant 媒体播放器播放合成语音：

每个事件都有 JSON 格式的 `Type` 和 `Data`，可在脚本中使用其值。

- 在 `synthesize` 步骤获取 `text` 的值，并调用 Home Assistant REST 接口
- 在 `audio-stop` 步骤获取合成语音时长（秒），等待相应时间后重新启动流程

```yaml
wyoming:
  script_example:
    event:
      synthesize: |
        let text = fromJSON(Data).text;
        let token = 'eyJhbGci...';
        fetch('http://localhost:8123/api/services/tts/speak', {
          method: 'POST',
          headers: {'Authorization': 'Bearer '+token,'Content-Type': 'application/json'},
          body: toJSON({
            entity_id: 'tts.google_translate_com',
            media_player_entity_id: 'media_player.google_nest',
            message: text,
            language: 'en',
          }),
        }).ok
      audio-stop: |
        let timestamp = fromJSON(Data).timestamp;
        let delay = string(timestamp)+'s';
        Sleep(delay) && WriteEvent("played") && Detect()
```

<a id="config-examples"></a>

## 配置示例

在 Windows 服务器上使用 FFmpeg 和 FFplay 的语音终端。

```yaml
streams:
  satellite_win:
    - exec:ffmpeg -hide_banner -f dshow -i "audio=Microphone (High Definition Audio Device)" -c pcm_s16le -ar 16000 -ac 1 -f wav -
    - exec:ffplay -hide_banner -nodisp -probesize 32 -f s16le -ar 22050 -#backchannel=1#audio=s16le/22050

wyoming:
  satellite_win:
    listen: :10700
    name: "Windows Satellite"
    wake_uri: tcp://192.168.1.23:10400
    vad_threshold: 1
```

在支持双向对讲的大华摄像头上运行语音终端。

```yaml
streams:
  dahua_camera:
    - rtsp://admin:password@192.168.1.123/cam/realmonitor?channel=1&subtype=1&unicast=true&proto=Onvif

wyoming:
  dahua_camera:
    listen: :10700
    name: "Dahua Satellite"
    wake_uri: tcp://192.168.1.23:10400
    vad_threshold: 1
```

使用外部 Wyoming 麦克风和音频输出的语音终端。

```yaml
streams:
  wyoming_external:
     - wyoming://192.168.1.23:10600                # wyoming-mic-external
     - wyoming://192.168.1.23:10601?backchannel=1  # wyoming-snd-external

wyoming:
   wyoming_external:
    listen: :10700
    name: "Wyoming Satellite"
    wake_uri: tcp://192.168.1.23:10400
    vad_threshold: 1
```

<a id="wyoming-external-microphone-and-sound"></a>

## Wyoming 外部麦克风与音频输出

希望使用 [Wyoming Satellite](https://github.com/rhasspy/wyoming-satellite) 项目的高级用户，可将 go2rtc 作为 [Wyoming External Microphone](https://github.com/rhasspy/wyoming-mic-external) 或 [Wyoming External Sound](https://github.com/rhasspy/wyoming-snd-external)。

**go2rtc.yaml**

```yaml
streams:
  wyoming_mic_external:
    - exec:ffmpeg -hide_banner -f dshow -i "audio=Microphone (High Definition Audio Device)" -c pcm_s16le -ar 16000 -ac 1 -f wav -
  wyoming_snd_external:
    - exec:ffplay -hide_banner -nodisp -probesize 32 -f s16le -ar 22050 -#backchannel=1#audio=s16le/22050

wyoming:
  wyoming_mic_external:
    listen: :10600
    mode: mic
  wyoming_snd_external:
    listen: :10601
    mode: snd
```

**docker-compose.yml**

```yaml
version: "3.8"
services:
  satellite:
    build: wyoming-satellite  # https://github.com/rhasspy/wyoming-satellite
    ports:
      - "10700:10700"
    command:
      - "--name"
      - "my satellite"
      - "--mic-uri"
      - "tcp://192.168.1.23:10600"
      - "--snd-uri"
      - "tcp://192.168.1.23:10601"
      - "--debug"
```

## Wyoming 外部源

**go2rtc.yaml**

```yaml
streams:
  wyoming_external:
    - wyoming://192.168.1.23:10600
    - wyoming://192.168.1.23:10601?backchannel=1
```

**docker-compose.yml**

```yaml
version: "3.8"
services:
   microphone:
      build: wyoming-mic-external  # https://github.com/rhasspy/wyoming-mic-external
      ports:
         - "10600:10600"
      devices:
         - /dev/snd:/dev/snd
      group_add:
         - audio
      command:
         - "--device"
         - "sysdefault"
         - "--debug"
   playback:
      build: wyoming-snd-external  # https://github.com/rhasspy/wyoming-snd-external
      ports:
         - "10601:10601"
      devices:
         - /dev/snd:/dev/snd
      group_add:
         - audio
      command:
         - "--device"
         - "sysdefault"
         - "--debug"
```
