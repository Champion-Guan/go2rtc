# Apple HomeKit

此模块同时支持 [Apple HomeKit](https://www.apple.com/home-app/accessories/) 协议的客户端和服务器。

<a id="homekit-client"></a>

## HomeKit 客户端

**Important:**

- **无需 Apple 设备**（iPhone、iPad 等）也可使用 HomeKit 摄像头，它只是另一种协议
- HomeKit 设备只能与一个生态系统配对。已与 iPhone（Apple 家庭）配对时，无法同时与 Home Assistant 或 go2rtc 配对；反之亦然
- HomeKit 设备应与 go2rtc 位于同一网络，并确保两者之间的 [mDNS](https://en.wikipedia.org/wiki/Multicast_DNS) 正常

go2rtc 支持从 [Home Assistant](../hass/说明书.md) 导入已配对的 HomeKit 设备。
因此可同时通过 Home Assistant 和 go2rtc 使用 HomeKit 摄像头。
使用 Home Assistant 时，建议先与它配对，以获得更多功能。

可在 HomeKit 页面与 go2rtc 配对；看不到设备时，请刷新页面。
也可尝试给 HomeKit 设备断电重启。如果仍无法发现设备，请检查 mDNS。

如果设备可见但没有配对按钮，说明它已与 Apple 家庭、Home Assistant、HomeBridge 等生态配对。请先从原生态删除设备；无法取消配对时，需要重置设备。

**Important:**

- HomeKit 音频使用特殊的 **AAC-ELD** 编码，参数非常规，且存在规范兼容性问题
- `VLC` 及多数其他播放器无法播放此音频
- 使用 MSE、WebRTC 等方式时，需要对音频转码

<a id="client-configuration"></a>

### 客户端配置

以下是通过 WebRTC、MSE、MP4、RTSP 使用 HomeKit 摄像头的推荐设置：

```yaml
streams:
  aqara_g3:
    - hass:Camera-Hub-G3-AB12
    - ffmpeg:aqara_g3#audio=aac#audio=opus
```

供普通播放器使用、带常规音频的 RTSP 链接：`rtsp://192.168.1.123:8554/aqara_g3?video&audio=aac`

**此视频源仍在积极开发中！**仅在 [Aqara Camera Hub G3](https://www.aqara.com/eu/product/camera-hub-g3) 的欧洲版和中国版上测试过。

<a id="homekit-server"></a>

## HomeKit 服务器

[`v1.7.0 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.7.0)

HomeKit 模块支持两种工作模式：

- 将任意 H264 摄像头导出到 Apple HomeKit
- 将 Apple HomeKit 摄像头（Aqara、Eve、Eufy 等）透明代理回 Apple HomeKit，保留 Apple 家庭中的全部摄像头功能，同时提供 RTSP、WebRTC、MP4 等输出

**Important**

- HomeKit 摄像头仅支持 H264 视频和 OPUS 音频

<a id="server-configuration"></a>

### 服务器配置

**最小配置**

```yaml
streams:
  dahua1: rtsp://admin:password@192.168.1.123/cam/realmonitor?channel=1&subtype=0
homekit:
  dahua1:  # same stream ID from streams list, default PIN - 19550224
```

**完整配置**

```yaml
streams:
  dahua1:
    - rtsp://admin:password@192.168.1.123/cam/realmonitor?channel=1&subtype=0
    - ffmpeg:dahua1#video=h264#hardware  # if your camera doesn't support H264, important for HomeKit
    - ffmpeg:dahua1#audio=opus           # only OPUS audio supported by HomeKit

homekit:
  dahua1:                   # same stream ID from streams list
    pin: 12345678           # custom PIN, default: 19550224
    name: Dahua camera      # custom camera name, default: generated from stream ID
    device_id: dahua1       # custom ID, default: generated from stream ID
    device_private: dahua1  # custom key, default: generated from stream ID
```

**代理 HomeKit 摄像头**

- HomeKit 摄像头到 Apple 设备（iPhone、Apple TV）的视频流会直接传输
- HomeKit 摄像头到 RTSP、WebRTC、MP4 等的视频流会经由 go2rtc 传输

```yaml
streams:
  aqara1:
    - homekit://...
    - ffmpeg:aqara1#audio=aac#audio=opus  # optional audio transcoding

homekit:
  aqara1:  # same stream ID from streams list
```
