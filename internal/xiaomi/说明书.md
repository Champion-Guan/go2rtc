# 小米米家

[`v1.9.13 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.9.13)

此源可观看 [Xiaomi Mi Home](https://home.mi.com/) 生态中的摄像头。

自 2020 年起，小米引入名为 `miss` 的统一摄像头协议，原作者认为其含义是 Mi Secure Streaming。在此之前，各型号的授权、加密、命令集和媒体数据包格式几乎都不同。

go2rtc 支持两种格式：`xiaomi/mess` 和 `xiaomi/legacy`。
支持多种点对点协议：`cs2+udp`、`cs2+tcp`，以及 `tutk+udp` 的多个版本。

几乎全部使用 `xiaomi/mess` 格式和 `cs2` 协议的摄像头都能正常工作。
较旧的 `xiaomi/legacy` 格式摄像头可能存在兼容性问题。
原作者认为 `tutk` 协议的点对点实现很不稳定。

**Important:**

1. **并非全部摄像头都受支持**，兼容列表见 [this issue](https://github.com/AlexxIT/go2rtc/issues/1982)
2. 每次连接摄像头都需要联网获取加密密钥
3. 仅支持本地连接

**Features:**

- 支持多个小米账户
- 单个账户支持多个地区的摄像头
- 支持双向对讲
- 支持多镜头摄像头

## 设置

1. 打开网页界面 > 添加 > 小米 > 使用用户名和密码登录
2. 如有要求，通过邮箱或手机接收验证码
3. 如有要求，完成图形验证码
4. 成功后账户将被添加，可从中加载摄像头

**Example**

```yaml
xiaomi:
  1234567890: V1:***

streams:
  xiaomi1: xiaomi://1234567890:cn@192.168.1.123?did=9876543210&model=isa.camera.hlc7
```

## 配置

`miss` 协议用 0 到 5 表示画质，通常 0 为自动、1 为标清、2 为高清。
go2rtc 默认设置为 2，但部分新型号用 3 表示高清。
旧型号在 3 档可能存在编码配置问题，因此不应给全部摄像头统一设置为 3。

可修改画质：`subtype=hd/sd/auto/0-5`。

```yaml
streams:
  xiaomi1: xiaomi://***&subtype=sd
```

双镜头摄像头可使用第二通道：`channel=2`。

```yaml
streams:
  xiaomi1: xiaomi://***&channel=2
```
