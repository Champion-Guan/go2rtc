# Yandex

用于从新款 [Yandex IP camera](https://alice.yandex.ru/smart-home/security/ipcamera) 获取流的源。

<a id="get-yandex-token"></a>

## 获取 Yandex 令牌

1. 安装 Home Assistant 集成 [YandexStation](https://github.com/AlexxIT/YandexStation)
2. 从 Home Assistant 配置目录复制令牌：`/config/.storage/core.config_entries`，键为 `"x_token"`

<a id="get-device-id"></a>

## 获取设备标识

1. 在任意浏览器打开 https://iot.quasar.yandex.ru/m/v3/user/devices
2. 复制摄像头标识，键为 `"id"`

<a id="configuration"></a>

## 配置

```yaml
streams:
  yandex_stream: yandex:?x_token=XXXX&device_id=XXXX
  yandex_snapshot: yandex:?x_token=XXXX&device_id=XXXX&snapshot
  yandex_snapshot_custom_size: yandex:?x_token=XXXX&device_id=XXXX&snapshot=h=540
```
