# HTTP

此源支持通过 HTTP 链接接收流。

可根据 `Content-Type` HTTP 响应头判断源格式：

- **HTTP-JPEG**（`image/jpeg`）：摄像头快照链接，go2rtc 可将其转换为 MJPEG 流
- **HTTP-MJPEG**（`multipart/x-mixed-replace`）：连续 JPEG 帧序列，带 HTTP 头
- **HLS**（`application/vnd.apple.mpegurl`）：常见的 [HTTP Live Streaming](https://en.wikipedia.org/wiki/HTTP_Live_Streaming) 格式，并非为实时媒体传输设计

> [!WARNING]
> HLS 并非实时格式，支持效果有限。建议通过 FFmpeg 源使用，并启用缓冲（默认关闭）。

## TCP

此源也支持 HTTP 和 TCP 流，并自动识别以下格式：

- `adts`：使用 [AAC](https://en.wikipedia.org/wiki/Advanced_Audio_Coding) 编码、带 ADTS 头的音频流
- `flv`：较旧但仍在使用的 [Flash Video](https://en.wikipedia.org/wiki/Flash_Video) 格式
- `h264` - AVC/H.264 bitstream.
- `hevc` - HEVC/H.265 bitstream.
- `mjpeg`：连续 JPEG 帧序列，不带 HTTP 头
- `mpegts`：传统 [MPEG transport stream](https://en.wikipedia.org/wiki/MPEG_transport_stream) 格式
- `wav`：[WAV](https://en.wikipedia.org/wiki/WAV) 格式音频流
- `yuv4mpegpipe`：带 YUV4MPEG 头的原始 YUV 帧流

## 配置

```yaml
streams:
  # [HTTP-FLV] video/x-flv 格式的视频流
  http_flv: http://192.168.1.123:20880/api/camera/stream/780900131155/657617
  
  # [JPEG] 大华摄像头快照，转换为 MJPEG 流
  dahua_snap: http://admin:password@192.168.1.123/cgi-bin/snapshot.cgi?channel=1

  # [MJPEG] 原样代理视频流
  http_mjpeg: https://mjpeg.sanford.io/count.mjpeg

  # [MJPEG、H.264/H.265 裸码流或 MPEG-TS]
  tcp_magic: tcp://192.168.1.123:12345

  # 添加自定义请求头
  custom_header: "https://mjpeg.sanford.io/count.mjpeg#header=Authorization: Bearer XXX"
```

**附注：**大华摄像头存在一个问题：RTSP 第二码流选择 MJPEG 后，快照将无法工作。
