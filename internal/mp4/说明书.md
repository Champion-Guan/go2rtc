# MP4

此模块提供以下功能：

1. MSE 流（通过 WebSocket 传输 fMP4）
2. MP4 格式摄像头快照（单帧），可发送到 [Telegram](#snapshot-to-telegram)
3. HTTP 渐进式播放（MP4 文件流）：启动延迟较高，不适合实时播放。Safari 不支持此方式，go2rtc 会自动重定向到 HLS/fMP4。

<a id="api-examples"></a>

## 接口示例

- MP4 snapshot: `http://192.168.1.123:1984/api/frame.mp4?src=camera1` (H264, H265)
- MP4 stream: `http://192.168.1.123:1984/api/stream.mp4?src=camera1` (H264, H265, AAC)
- MP4 file: `http://192.168.1.123:1984/api/stream.mp4?src=camera1` (H264, H265*, AAC, OPUS, MP3, PCMA, PCMU, PCM)
    - 可使用 `mp4`、`mp4=flac` 和 `mp4=all` 参数过滤编码
    - `duration` 参数单位为秒，例如 `duration=15`
    - 可使用 `filename` 参数，例如 `filename=record.mp4`
    - `rotate` 参数可取 `90`、`180` 或 `270`
    - `scale` 参数可取正整数，例如 `scale=4:3`

更多信息见 [codecs filters](../../说明书.md#codecs-filters)。

**附注：**旋转和缩放参数通过元数据修改视频，无需转码。

<a id="snapshot-to-telegram"></a>

## 将快照发送到 Telegram

以下示例用于 Home Assistant 的 [Telegram Bot](https://www.home-assistant.io/integrations/telegram_bot/) 集成。

- 将 `url` 改为 go2rtc 网页接口地址，多数用户为 `http://localhost:1984/`
- 将 `target` 改为 Telegram 聊天标识，支持列表
- 将 `src=camera1` 改为 go2rtc 配置中的流名称

**重要：**多数摄像头和视频源能近乎即时生成快照，但 `ffmpeg` 源除外，因为 FFmpeg 启动视频流较慢，即使使用 `#video=copy` 也一样。未从关键帧开始输出的摄像头也可能产生延迟。

<a id="snapshot-from-h264-or-h265-camera"></a>

### H264 或 H265 摄像头快照

```yaml
service: telegram_bot.send_video
data:
  url: http://localhost:1984/api/frame.mp4?src=camera1
  target: 123456789
```

<a id="record-from-h264-or-h265-camera"></a>

### H264 或 H265 摄像头录像

从服务调用时刻开始录制后续画面，不支持回溯录像。

- `mp4=flac`：增加 PCM 系列音频支持
- `filename=record.mp4`：设置下载文件名

```yaml
service: telegram_bot.send_video
data:
  url: http://localhost:1984/api/stream.mp4?src=camera1&mp4=flac&duration=5&filename=record.mp4  # duration in seconds
  target: 123456789
```

<a id="snapshot-from-jpeg-or-mjpeg-camera"></a>

### JPEG 或 MJPEG 摄像头快照

此示例通过 [mjpeg](../mjpeg/说明书.md) 模块工作。

```yaml
service: telegram_bot.send_photo
data:
  url: http://localhost:1984/api/frame.jpeg?src=camera1
  target: 123456789
```
