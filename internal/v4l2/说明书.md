# Video4Linux

[`v1.9.9 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.9.9)

关于 [V4L2](https://en.wikipedia.org/wiki/Video4Linux)，需要了解：

- V4L2（Linux 视频接口第 2 版）仅支持 Linux
- 支持 USB 摄像头及类似设备
- 同一设备同一时间只能由一个软件连接
- 摄像头支持的格式、分辨率和帧率列表是固定的
- 基础摄像头仅支持未压缩的 RAW 像素格式
- 普通摄像头支持 MJPEG，即连续 JPEG 帧
- 高级摄像头支持 H264，兼容 MSE/MP4 和 WebRTC
- 摄像头支持 MJPEG 或 H264 时，直接使用不会产生转码 CPU 开销
- RAW 转码为 MJPEG 或 H264 会显著占用 CPU
- 摄像头支持时，也可使用 H265（HEVC）

测试中，基础款 MIPS 处理器 Keenetic 路由器可同时转发三路 MJPEG，分辨率为 1600×1200、640×480、640×480，CPU 占用不超过 5%；更高分辨率会受 USB 总线带宽限制。

可在 **go2rtc > 网页界面 > 添加 > V4L2** 查看摄像头支持的格式。

## RAW 原始格式

Example:

```yaml
streams:
  camera1: v4l2:device?video=/dev/video0&input_format=yuyv422&video_size=1280x720&framerate=10
```

go2rtc 内置 RAW 到 MJPEG 的转码，无需额外配置。

```
ffplay http://localhost:1984/api/stream.mjpeg?src=camera1
```

**重要：**RAW 无需转码即可通过网络传输，可使用 FFmpeg 完整支持的 `y4m` 格式。这没有转码 CPU 开销，但需要较高带宽。

```
ffplay http://localhost:1984/api/stream.y4m?src=camera1
```
