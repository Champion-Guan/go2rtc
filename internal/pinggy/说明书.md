# Pinggy

[Pinggy](https://pinggy.io/)：为本地服务提供公网隧道的服务。

**Features:**

- 免费账户无需注册
- 无需下载第三方二进制，通过 SSH 协议工作
- 支持 HTTP、TCP 和 UDP
- 为 HTTP 服务提供 HTTPS

> [!IMPORTANT]
> 免费账户使用随机地址，隧道仅持续一小时，只适合测试。

> [!CAUTION]
> 未经身份验证就开放 go2rtc 公网访问会危及整个家庭网络，请谨慎配置。

**Why:**

- 方便设置 HTTPS 来测试双向对讲
- 方便检查 WebRTC 外部访问能否工作
- 排查问题需要时，可向 go2rtc 开发者提供 RTSP 或 HTTP 摄像头的直接访问链接

<a id="configuration"></a>

## 配置

启动后可在 go2rtc 日志中找到公网链接。

**为 go2rtc 网页界面建立隧道。**

```yaml
pinggy:
  tunnel: http://localhost:1984
```

**为 RTSP 摄像头建立隧道。**

例如摄像头地址为 `rtsp://admin:password@192.168.1.123/cam/realmonitor?channel=1&subtype=0`：

```yaml
pinggy:
  tunnel: tcp://192.168.10.91:554
```

go2rtc 日志会出现类似输出：

```
16:17:43.167 INF [pinggy] proxy url=tcp://abcde-123-123-123-123.a.free.pinggy.link:12345
```

现在可以使用以下流：

```
rtsp://admin:password@abcde-123-123-123-123.a.free.pinggy.link:12345/cam/realmonitor?channel=1&subtype=0
```
