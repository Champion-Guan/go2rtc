# 海康威视 ISAPI

[`v1.3.0 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.3.0)

此源仅支持 [Hikvision ISAPI](https://tpp.hikvision.com/download/ISAPI_OTAP) 协议的音频回传，应作为 RTSP 之外的第二个源使用。

<a id="configuration"></a>

## 配置

```yaml
streams:
  hikvision1:
    - rtsp://admin:password@192.168.1.123:554/Streaming/Channels/101
    - isapi://admin:password@192.168.1.123:80/
```
