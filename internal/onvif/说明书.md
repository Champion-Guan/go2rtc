# ONVIF

<a id="onvif-client"></a>

## ONVIF 客户端

[`v1.5.0 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.5.0)

已知摄像头 RTSP 和快照链接时，此源作用有限；未知时则可能有用。

**网页界面 > 添加**支持 ONVIF 自动发现。服务器必须与摄像头位于同一子网；Docker 部署需要使用主机网络模式（network host）。

```yaml
streams:
  dahua1: onvif://admin:password@192.168.1.123
  reolink1: onvif://admin:password@192.168.1.123:8000
  tapo1: onvif://admin:password@192.168.1.123:2020
```

<a id="onvif-server"></a>

## ONVIF 服务器

普通摄像头有一个视频源（`GetVideoSources`）和两个配置档（`GetProfiles`）。

go2rtc 为每个流提供一个视频源和一个配置档。

<a id="tested-clients"></a>

## 已测试的客户端

go2rtc 作为 ONVIF 服务器已测试：

- Happytime ONVIF 客户端（Windows）
- Home Assistant ONVIF 集成（Linux）
- Onvier（Android）
- ONVIF Device Manager（Windows）

附注：RTSP 仅支持 TCP 传输，暂不支持 UDP 和 HTTP 传输。
