# Wyze

[`v1.9.14 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.9.14) by [@seydx](https://github.com/seydx)

此源使用原生点对点协议获取 [Wyze](https://wyze.com/) 摄像头流，无需 Wyze 应用或 SDK。

**Important:**

1. **需要 Wyze 账户**，先通过网页界面登录一次以加载摄像头
2. **需要支持 DTLS 的固件**，只支持启用 DTLS 的摄像头固件
3. 仅从账户加载摄像头时需要联网，此后流传输均为本地点对点连接
4. 只支持本地连接，即直接连接摄像头 IP

**Features:**

- 支持 H.264 和 H.265 视频编码
- 支持 AAC、G.711、PCM 和 Opus 音频编码
- 支持双向对讲
- 支持高清/标清分辨率切换

## 设置

1. 从 [Wyze Developer Portal](https://support.wyze.com/hc/en-us/articles/16129834216731) 获取 API 密钥
2. 打开网页界面 > 添加 > Wyze
3. 填写 API 标识、API 密钥、邮箱和密码
4. 选择要添加的摄像头，流地址会自动生成

**配置示例**

```yaml
wyze:
  user@email.com:
    api_id: "your-api-id"
    api_key: "your-api-key"
    password: "yourpassword"    # or MD5 triple-hash with "md5:" prefix

streams:
  wyze_cam: wyze://192.168.1.123?uid=WYZEUID1234567890AB&enr=xxx&mac=AABBCCDDEEFF&model=HL_CAM4&dtls=true
```

<a id="stream-url-format"></a>

## 流地址格式

通过网页界面添加摄像头时，会自动生成流地址：

```
wyze://[IP]?uid=[P2P_ID]&enr=[ENR]&mac=[MAC]&model=[MODEL]&subtype=[hd|sd]&dtls=true
```

| Parameter | Description                                     |
|-----------|-------------------------------------------------|
| `IP`      | Camera's local IP address                       |
| `uid`     | P2P identifier (20 chars)                       |
| `enr`     | Encryption key for DTLS                         |
| `mac`     | Device MAC address                              |
| `model`   | Camera model (e.g., HL_CAM4)                    |
| `dtls`    | Enable DTLS encryption (default: true)          |
| `subtype` | Camera resolution: `hd` or `sd` (default: `hd`) |

<a id="configuration"></a>

## 配置

<a id="resolution"></a>

### 分辨率

可使用 `subtype` 参数修改摄像头分辨率：

```yaml
streams:
  wyze_hd: wyze://...&subtype=hd
  wyze_sd: wyze://...&subtype=sd
```

<a id="two-way-audio"></a>

### 双向对讲

自动支持双向对讲。消费者向流发送音频时，会转发到摄像头扬声器。
