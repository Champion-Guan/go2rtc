# TP-Link Tapo

[`v1.2.0 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.2.0)

[TP-Link Tapo](https://www.tapo.com/) 的私有摄像头协议，支持**双向对讲**。

- 流质量与 [RTSP protocol](https://www.tapo.com/en/faq/34/) 相同
- 使用**云账户密码**，不是 RTSP 密码；无需填写用户名
- 也可使用云密码的**大写 MD5 哈希**，用户名为 `admin`
- 部分新固件要求 SHA256，而不是 MD5

<a id="configuration"></a>

## 配置

```yaml
streams:
  # 仅使用云端密码，不使用用户名
  camera1: tapo://cloud-password@192.168.1.123
  # 使用 admin 用户名及云端密码的大写 MD5 哈希
  camera2: tapo://admin:UPPERCASE-MD5@192.168.1.123
  # 使用 admin 用户名及云端密码的大写 SHA256 哈希
  camera3: tapo://admin:UPPERCASE-SHA256@192.168.1.123
  # VGA 视频流（子码流，分辨率较低）
  camera4: tapo://cloud-password@192.168.1.123?subtype=1 
  # HD stream (default)
  camera5: tapo://cloud-password@192.168.1.123?subtype=0 
```

```bash
echo -n "cloud password" | md5 | awk '{print toupper($0)}'
echo -n "cloud password" | shasum -a 256 | awk '{print toupper($0)}'
```

## TP-Link Kasa

[`v1.7.0 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.7.0)

> [!NOTE]
> 此源的代码与 Tapo 无关，应移到独立模块。

[TP-Link Kasa](https://www.kasasmart.com/) 使用非标准协议 [more info](https://medium.com/@hu3vjeen/reverse-engineering-tp-link-kc100-bac4641bf1cd)。

- `username`：适用于 URL 的邮箱编码，`alex@gmail.com` 转为 `alex%40gmail.com`
- `password` - base64password, `secret1` -> `c2VjcmV0MQ==`

```yaml
streams:
  kc401: kasa://username:password@192.168.1.123:19443/https/stream/mixed
```

Tested: KD110, KC200, KC401, KC420WS, EC71.

## TP-Link Vigi

[`v1.9.8 新增`](https://github.com/AlexxIT/go2rtc/releases/tag/v1.9.8)

[TP-Link VIGI](https://www.vigi.com/) 摄像头属于不同子品牌，但格式与 Tapo 非常相似，仅授权方式不同，详情见 [此处](https://github.com/AlexxIT/go2rtc/issues/1470)。

```yaml
streams:
  camera1: vigi://admin:{password}@192.168.1.123
```
