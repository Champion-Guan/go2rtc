# FFmpeg

可通过 FFmpeg 获取任意流、文件或设备，并推送给 go2rtc。有人开始观看时，应用会自动使用合适的参数启动 FFmpeg。

- **Docker** 和 **Home Assistant 附加组件**已预装 FFmpeg
- **Home Assistant 附加组件**可读取 [/media](https://www.home-assistant.io/more-info/local-media/setup-media/) 目录中的文件

<a id="configuration"></a>

## 配置

Format: `ffmpeg:{input}#{param1}#{param2}#{param3}`. Examples:

```yaml
streams:
  # [FILE] 直接复制所有轨道，不进行转码
  file1: ffmpeg:/media/BigBuckBunny.mp4

  # [FILE] 视频转码为 H264，跳过音频
  file2: ffmpeg:/media/BigBuckBunny.mp4#video=h264

  # [FILE] 直接复制视频，音频转码为 PCMU
  file3: ffmpeg:/media/BigBuckBunny.mp4#video=copy#audio=pcmu

  # [HLS] 直接复制视频，跳过音频
  hls: ffmpeg:https://devstreaming-cdn.apple.com/videos/streaming/examples/bipbop_16x9/gear5/prog_index.m3u8#video=copy

  # [MJPEG] 视频转码为 H264
  mjpeg: ffmpeg:http://185.97.122.128/cgi-bin/faststream.jpg#video=h264

  # [RTSP] 旋转视频需要转码，因此选择 H264
  rotate: ffmpeg:rtsp://12345678@192.168.1.123/av_stream/ch0#video=h264#rotate=90
```

全部转码格式都有 [built-in templates](ffmpeg.go)：`h264`、`h265`、`opus`、`pcmu`、`pcmu/16000`、`pcmu/48000`、`pcma`、`pcma/16000`、`pcma/48000`、`aac`、`aac/16000`。

可通过 YAML 配置覆盖它们，也可添加自定义格式并在源参数中使用。

```yaml
ffmpeg:
  bin: ffmpeg  # path to ffmpeg binary
  global: "-hide_banner"
  timeout: 5  # default timeout in seconds for rtsp inputs
  h264: "-codec:v libx264 -g:v 30 -preset:v superfast -tune:v zerolatency -profile:v main -level:v 4.1"
  mycodec: "-any args that supported by ffmpeg..."
  myinput: "-fflags nobuffer -flags low_delay -timeout {timeout} -i {input}"
  myraw: "-ss 00:00:20"
```

- 可用 go2rtc 流名称作为 FFmpeg 输入，例如 `ffmpeg:camera1#video=h264`
- `video` 和 `audio` 参数可重复使用，例如 `#video=copy#audio=copy#audio=pcmu`
- 转码时可使用 `rotate` 参数，取值为 `90`、`180`、`270` 或 `-90`，例如 `#video=h264#rotate=90`
- 转码时可指定 `width` 和/或 `height` 参数，例如 `#video=h264#width=1280`
- 可用 `drawtext` 添加时间戳，例如 `drawtext=x=2:y=2:fontsize=12:fontcolor=white:box=1:boxcolor=black`
    - 即使启用硬件加速，也会显著提高服务器 CPU 占用
- `timeout` 参数可设置 RTSP 输入超时，单位为秒，例如 `#timeout=10`
- `raw` 参数可添加任意 FFmpeg 参数，例如 `#raw=-vf transpose=1`
- `input` 参数可覆盖默认输入模板，例如 `#input=rtsp/udp` 将 RTSP 传输从 TCP 改为 UDP+TCP
    - 也可以使用原始输入值，例如 `#input=-timeout {timeout} -i {input}`
    - 可以添加自定义输入模板

更多信息见 [hardware acceleration](hardware/说明书.md)。

**附注：**建议在网页界面的添加页面检查可用硬件。
