# Docker

镜像通过 [GitHub actions](https://github.com/AlexxIT/go2rtc/actions) 自动构建，并发布到 [Docker Hub](https://hub.docker.com/r/alexxit/go2rtc) 和 [GitHub](https://github.com/AlexxIT/go2rtc/pkgs/container/go2rtc)。

## 版本

- `alexxit/go2rtc:latest`：基于 `alpine` 的最新发行版（`amd64`、`386`、`arm/v6`、`arm/v7`、`arm64`），支持 Intel 核显和树莓派硬件转码
- `alexxit/go2rtc:latest-hardware`：基于 `debian 13` 的最新发行版（`amd64`），支持 Intel 核显、AMD 和 NVIDIA 显卡硬件转码
- `alexxit/go2rtc:latest-rockchip`：基于 `debian 12` 的最新发行版（`arm64`），支持瑞芯微 RK35xx 硬件转码
- `alexxit/go2rtc:master`：基于 `alpine` 的最新不稳定版本
- `alexxit/go2rtc:master-hardware`：基于 `debian 13` 的最新不稳定版本（`amd64`）
- `alexxit/go2rtc:master-rockchip`：基于 `debian 12` 的最新不稳定版本（`arm64`）

<a id="docker-compose"></a>

## Docker Compose 编排

```yaml
services:
  go2rtc:
    image: alexxit/go2rtc
    network_mode: host       # important for WebRTC, HomeKit, UDP cameras
    privileged: true         # only for FFmpeg hardware transcoding
    restart: unless-stopped  # autorestart on fail or config change from WebUI
    environment:
      - TZ=Atlantic/Bermuda  # timezone in logs
    volumes:
      - "~/go2rtc:/config"   # folder for go2rtc.yaml file (edit from WebUI)
```

<a id="basic-deployment"></a>

## 基础部署

```bash
docker run -d \
  --name go2rtc \
  --network host \
  --privileged \
  --restart unless-stopped \
  -e TZ=Atlantic/Bermuda \
  -v ~/go2rtc:/config \
  alexxit/go2rtc
```

<a id="deployment-with-gpu-acceleration"></a>

## 使用 GPU 加速部署

```bash
docker run -d \
  --name go2rtc \
  --network host \
  --privileged \
  --restart unless-stopped \
  -e TZ=Atlantic/Bermuda \
  --gpus all \
  -v ~/go2rtc:/config \
  alexxit/go2rtc:latest-hardware
```
